# Baroque frame references

The three PNGs were supplied by the user for this prototype and copied without alteration.

- `baroque-gold.png`: gold rectangular moulding reference.
- `baroque-silver.png`: ornate silver rectangular frame reference.
- `baroque-ornaments.png`: silver oval frame; the top ornamental section supplies the crest and inverted pendant of the third variant.

The renderer maps eight source-image panels around a rectangular opening. Extruded bevelled geometry provides the frame body; instanced spheres provide the raised beaded lip. Fine carvings and crest silhouettes are photographic textures, not individually sculpted relief. White source background is discarded in the material shader. Artwork is never cropped into the oval source opening.

No third-party ownership or redistribution license is inferred from these supplied references. Original source attribution and any publishing permissions remain to be confirmed before public distribution.
